# 柚影：产品与工程状态

## 定位

一个 Android Flutter 媒体客户端开发原型，不是原应用的原始源码，也不是已经上线的商业产品。
沿用证据确认的播放器通道名与参数结构，Media3 Android 实现和业务代码独立编写。
原 APK 的字符串、类声明和 AOT 元数据存放在历史分析目录，不把它们冒充可编译业务源码。

## 能否正常使用？

**作为继续开发的工程可以；不能承诺开箱就能看视频或已经可以上线。**
工程编译检查与自动化测试只证明代码和构建基线，不证明真实手机、真实视频源或播放体验。
原应用搜索、详情和解析 API 仍未确认。历史运行时证据已有播放器输入 M3U8，但单集地址不是可搜索源，也不能证明上游接口已恢复。
SDK 广告/统计/文档地址不属于已确认影视源，也不自动加入本工程。

尚需验收：

- 用户手机 USB 启动、横竖屏、后台恢复、断网行为与设备兼容性。
- 有授权的 HTTPS 源联调：搜索、封面、选集、鉴权、错误响应。
- 真实 HLS / DASH 播放、暂停、拖动、倍速、续播和音视频同步。
- 直接文件与无加密 HLS 下载、本地离线播放；取消、后台任务和断点续传尚未实现。
- 用户自己的长期签名密钥、版本升级及发布渠道要求。

不要使用未知来源的服务、账号或密钥来填补这些验收项。
只添加有权使用的视频源；本工程不绕过 DRM 或访问权限。

## 与小柚子页面的差异

**主要页面结构已按截图对齐，不宣称像素级复刻或恢复原后台。** 底部现为首页、排行榜、我的。
首页包含搜索、分类横栏、可滑动的内容横幅、海报更新区；排行榜采用圆角海报/简介卡片；我的包含本地头像、历史横排与功能网格。
不含登录、广告、系统消息或留言求片；收藏、历史、下载、设置与直链播放入口保留。
没有原应用热度数据，不把更新列表伪装成日榜；AI 漫剧仅在源明确提供分类时可用，当前点播源不支持电视直播。
横幅使用源封面而非原应用运营素材。详见 `07-ui-alignment.md`。

## 命名 / 安全约定

- Dart 包：`youying`；界面名称：柚影。
- release：`dev.youying.app`；debug/test：`dev.youying.app.debug`。
- 各包独立数据；卸载会删除所属应用的本地数据，不自动迁移旧包。
- 正式签名不得使用 Android debug 证书。密钥由用户保管，工程不附带生产密钥。
- 本工程编译通过不证明原 APK 无病毒；本轮没有有效杀毒扫描或原 APK 动态安全结论。
- Android 之外的平台尚未实现，不能把当前工程当作跨平台产品交付。
