# 资源适配与下载（2026-10-13）

## 先明确可用性

这是独立重写的兼容层，不是原 APK 服务协议。没有内置影视源，安装后不会自动获得片库。
只有配置了有权使用、符合下述协议的 HTTPS 服务，搜索 → 详情 → 选集 → 换线 → 下载才具备联调条件。
现有播放器 M3U8 证据只代表某一集在某次运行中的输入，不能拿来当搜索 API。

## 源接口约定

- 搜索：`GET <endpoint>?ac=videolist&wd=<UTF-8 keyword>`。
- 详情：`GET <endpoint>?ac=detail&ids=<vod_id>`；必须返回相同资源 ID，不能误取第一条无关结果。
- 保留 endpoint 自带的非控制参数；每次清理旧 `ac`、`wd`、`ids`、`pg`，避免搜索与详情条件混用。
- 不自动跟随 3xx，不接受 HTTP 或 URL 中的用户名/密码。响应为 UTF-8 JSON，单次上限 2 MiB，连接/流空闲超时 15 秒。
- 支持顶层数组、`list`、`data` 数组，以及 `data.list` / `data.items`。
- 字段：`vod_id/id`、`vod_name/title`、`vod_pic/poster`、`vod_content/description`。
- 线路：`vod_play_from` 使用 `$$$` 分隔；`vod_play_url/play_url` 使用 `$$$` 分线路、`#` 分集、`$` 分集名和 URL。
- 未返回 ID 的列表仍可播放已有线路，但不能自动请求详情。历史记录旧数据没有 `remoteId` 时需重新搜索。
- 详情失败保留已有线路，页面可重试。自定义源不是所有私有接口的通用适配器。

换线优先找同名集，其次沿用原集数索引；均无匹配时选目标线路第一集。正常匹配换线请求沿用播放位置。
不同服务的集名/集数不一致时需要手动确认，不能保证其节目内容一致。

## 下载范围

- 前台 MP4/WebM；支持有长度或无 Content-Length 的有限响应，累计上限 2 GiB。
- URL 路径以 `.m3u8` 结尾的无加密 HLS 点播：必须有 `#EXT-X-ENDLIST`；支持普通 TS、fMP4 初始化片段与相对地址。
- 支持不超过 4 层清单；主清单选择第一个音视频合并的 variant。最多 5000 个资源引用，每份清单最多 2 MiB。
- 清单中的分片下载为本地文件，并重写本地 `index.m3u8`；全部成功后才原子改名进入完成目录，失败清理临时文件。
- UI 显示字节进度；长度已知的直链显示百分比进度条。下载目标在开始时固定，不因切集改变。
- 手动播放时输入的请求头也用于下载，但只发往最初 URL 的同源地址，不跨域转发凭证。跨域 CDN 需要额外鉴权时会失败，不尝试绕过。
- 拒绝直播、加密 HLS（包括 AES-128）、DRM、DASH 下载、字节范围、分离音轨/字幕、未知 HLS 扩展与重定向。
- 暂无取消、后台服务、断点续传。进程被系统强制结束时可能留下 `.partial` 目录，需要清理后重试；不得把下载按钮当后台任务保证。
- 本地 HLS 播放由现有 Media3 桥接处理；真实设备离线播放与长视频仍需验收。
