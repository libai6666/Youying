# 公开源预设与界面差异

> 源表历史记录：本轮已新增 5 个源、移除无尽/量子的旧接口，现有 7 个预设。当前清单与媒体限制见 [新增五源与升级验证](08-public-sources-v2.md)，下表保留早期观测，不代表当前预设。

## 本轮结论

为柚影加入 4 个公开源候选，**只有 360、极速在用户 Windows 本机通过搜索、详情、HLS 清单抽查**，不代表已通过 Android 播放验收，也不代表内容已获授权。
源表来自 [vodtv/api](https://github.com/vodtv/api) 的 [jin18.json](https://raw.githubusercontent.com/vodtv/api/main/jin18.json)。没有引入该仓库程序、TVBox spider、第三方代理或自动远程配置更新。

| 预设 | HTTPS JSON API | 初始状态 | 本机历史观测 |
| --- | --- | --- | --- |
| 360资源 | https://360zyzz.com/api.php/provide/vod | 启用 | 搜索 3 条；详情 ID 匹配；主/子 HLS 清单 HTTP 200 |
| 极速资源 | https://jszyapi.com/api.php/provide/vod | 启用 | 搜索 4 条；详情 ID 匹配；HLS 清单 HTTP 200 |
| 无尽资源 | https://api.wujinapi.me/api.php/provide/vod | 停用 | HTTP 403；不能标为可用 |
| 量子资源 | https://cj.lzcaiji.com/api.php/provide/vod | 停用 | HTTP 403；不能标为可用 |

观测日期为执行机器 UTC 2026-10-14（证据 JSON 的 `utc` 字段）。关键词为“大闹天宫”，每个固定候选只进行一次搜索、最多一次详情和有限清单检查；没有批量翻页、请求加密 key、下载影片或绕过访问控制。
360 和极速抽查样本的媒体清单均含 AES-128 分片加密，当前下载器会拒绝；此限制不等同于断言 Android 播放器一定无法播放。
无尽此前云端与本机结果不同，不能把云端成功当作手机成功。

另外抽查的魔都资源、最大、iKun、魔都动漫、飘零、速播均在本机返回 HTTP 403；茅台 HTTP 200 但缺少可兼容的 `list`。没有把这些加入默认搜索。
之前的暴风也返回 HTTP 403。未使用变更认证、代理、关闭 TLS 或伪装方式绕过。

## 配置与行为

- 初次启动或升级时添加预设一次；以名称或完整 URL 去重，不覆盖用户已有同名/同 URL 的配置和启停状态，不改动收藏、历史、下载记录。
- 老版本没有 `enabled` 字段的手动源仍默认为启用。已初始化后删除全部源，也不会在重启时恢复。
- 在“设置”可以启停、移除或手动添加 HTTPS JSON 源。失败候选明确标注历史失败，不显示实时健康标记。
- 仅搜索已启用源，逐源显示结果数量或错误；一个源失败不阻断后续源。当前仍为顺序搜索，每源超时 15 秒。
- 停用后不再开始该源的搜索/详情请求，不取消已经开始的请求或正在播放的媒体。
- 旧版不在启动时请求源；页面对齐版会自动请求所选已启用源的分类和首页内容，仍不自动拉取 GitHub 配置。
- 接口解析只保留路径后缀为 `.m3u8`、`.mp4`、`.webm`、`.mpd` 的 HTTPS 媒体线路；保留其查询参数，排除网页播放器/分享页。无后缀播放接口暂不支持自动识别，可通过手动直链入口自行验证有权访问的媒体。
- 页面里的抽查日期/结论是静态历史记录，不是源健康监控。清除应用数据或重装会重建初始预设。

## 页面是否与小柚子相同？

**主要布局已按三张截图对齐，但不是原应用的完整复刻。** 最新状态：

| 小柚子截图 | 柚影目前 |
| --- | --- |
| 首页搜索、分类横栏、轮播、热播推荐 | 搜索入口、分类栏、手动滑动横幅、剧集/综艺/动漫更新；不伪造热播推荐 |
| 电视剧/电影/动漫/综艺/短剧日榜 | 对齐卡片布局，按源返回顺序展示，明确标注非热度榜 |
| 底部“首页 / 排行榜 / 我的” | 已改为相同的三栏结构 |
| 未登录头像、历史横排、常用功能网格 | 本地观影头像、历史横排与功能网格；按要求不加登录 |
| 分享 APP、系统消息、留言求片 | 未实现，不生成虚假入口或数据 |
| 原应用账号及业务服务 | 未恢复；只有本地持久化，没有云端账号同步 |

源预设轮次未修改布局；后续页面对齐轮次已实现以上界面与分类接口。没有复用原应用商标和运营数据，没有加入登录或广告 SDK。
真实热度数据未接入，直播以及源未提供的分类会显示明确提示。详细行为和测试见 `07-ui-alignment.md`。
