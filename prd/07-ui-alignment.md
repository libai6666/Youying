# 三栏页面对齐说明

> 本文记录三栏 UI 阶段的构建与 57 项测试。后续源扩充已通过 62 项测试，但未重新打包；当前源表与验收边界见 [公共源第二轮扩充](08-public-sources-v2.md)。

## 目标与完成范围

依据用户提供的首页、排行榜、我的三张截图，调整整体结构、配色与内容密度，不恢复原应用账号、广告或运营后台。

| 页面 | 本轮实现 |
| --- | --- |
| 首页 | 橙色到浅灰渐变、圆角搜索框、下载/历史入口、横向分类栏、内容源切换、五项可手动滑动横幅、剧集/综艺/动漫海报更新行、继续观看入口 |
| 分类片库 | 根据源实际分类 ID 请求列表，海报网格、加载更多、加载/失败/空状态 |
| 排行榜 | 深色渐变页头、五类标签、海报/年份/地区/简介/演员标签卡片；明确标注“源更新顺序 · 非热度榜” |
| 我的 | 本地观影头像、观看历史横排、收藏/下载/历史/设置/直链播放/关于入口；没有登录、消息或求片伪功能 |
| 内页 | 海报化搜索结果、详情海报与收藏入口，保留详情刷新、线路/集数、播放器与下载的原有流程 |

项目仍称“柚影”。没有复制原应用商标、登录页、广告 SDK 或推广服务。
横幅取自所选源的前五项封面，可左右滑动，不是原应用的运营横幅，也不进行自动定时轮播。

## 数据与网络行为

- 启动首页后，选择首个已启用源；可以通过源名称下拉菜单切换。全停用或全部删除时显示设置入口，不进行片库请求。
- 分类接口：`ac=list&pg=1`，读取 `class` 中的 `type_id/type_name/type_pid`。
- 列表接口：`ac=videolist&pg=页码&t=分类ID`；无分类 ID 时请求综合列表。每次仅请求一页，不自动无限翻页。
- 首页同时请求综合列表和分类，随后请求已识别的电视剧、综艺、动漫各一页。数据按接口返回顺序展示，没有算法推荐或热度评分。
- 识别“连续剧/电视剧”“动漫/动画”“爽文短剧/短剧”等已知名称；不假定不同源的分类 ID 相同。未知分类不硬编码到其他类别。
- 用户选择过的分类在刷新/换源后可重新请求；点击“加载更多”才请求后续页，按资源 ID 去重。
- 只允许 HTTPS 接口；沿用超时、响应体上限和禁止自动跟随接口重定向的规则。海报只渲染 HTTPS 地址，失败则显示占位图。
- 切换/移除源后丢弃旧请求的迟到结果；已发出的请求不强制取消。收藏、历史等本地状态变化不重复请求首页。
- 不自动拉取远程源配置、不执行 TVBox spider、不绕过 403、TLS 或媒体加密。
- 搜索仍由用户提交关键词后进行，只搜索已启用源，逐源报告失败，不受片库页当前选源限制。

## 实际接口观察

在用户 Windows 本机对 360 资源各请求一次分类和综合列表，均 HTTP 200；分类包含电影、连续剧、综艺、动漫、爽文短剧等，列表返回 `vod_*` 元数据与页数。
这只证明该环境下这些 HTTP 请求当时成功，不证明所有分类长期可用，也不代表 Android 封面、播放或下载验收通过。

## 验证

- `flutter analyze` 无问题。
- 全量 57 项单元/组件测试通过，含新增 13 项片库和页面测试。
- 新覆盖分类参数、元数据兼容、分页去重、请求失败重试、停用无请求、换源迟到结果隔离和销毁后异步安全。
- 组件测试覆盖三栏导航、搜索/收藏/下载/设置入口、非热度提示、不支持分类提示、320px 小屏和 1.3 倍字体。
- 三张预览由真实 Flutter 页面配合**测试数据与占位海报**渲染，不是真机截图，不代表实际媒体播放。
- Android ARM64 构建、签名和本机交付结果以交付说明为准。

## 保留的限制

- 不是像素级复刻；没有原应用的日榜、后台推荐、原账号数据、系统消息、留言求片或运营横幅。
- AI 漫剧只有源明确返回独立分类时可用；不能把全部短剧冒充 AI 漫剧。当前点播源没有接入电视直播。
- 真机安装、界面操作、封面、播放、下载、离线观看仍未验收。没有操作 MuMu 主实例，也没有安装或修改原 APK。
- 360/极速此前抽查清单含 AES-128；当前下载器仍拒绝加密 HLS，不请求 key，不因 UI 改版而改变这一边界。
- 下载仍是前台有限支持，没有后台任务、取消或断点续传；使用第三方源必须自行确认内容授权。
