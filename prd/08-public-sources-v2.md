# 公共源第二轮扩充与失效接口清理

## 1. 本轮结果

新增 **5 个**：猫眼资源（第三方）、豪华资源、光速资源、如意资源、红牛资源。
保留 360资源、极速资源；移除无尽、量子的旧失效接口。新装共 **7 个预设**，默认启用；升级时保留已有源的启停状态。

**七源均在用户 Windows 本机通过搜索、详情、分类和首页列表请求；这不等于七源均可播放。** 红牛的媒体清单持续 TLS 失败，暂只能确认搜索/片库接口可用；源设置已提示该限制。没有进行 Android 播放器或整片下载验收。

本轮只改源码、测试和文档，**没有执行 APK 构建、安装或签名操作**。由用户使用现有构建脚本自行打包。Git 未提交、未推送。

## 3. 旧配置升级

由 `public_sources_initialized_v2` 控制一次性迁移：

1. 新装使用当前七源，不再加入两条退役 URL。
2. 已完成 v1 初始化的用户只补充五个 v2 新源；不重新添加用户之前删除的 360/极速。
3. 按 URL 精确移除两条退役接口，即使它们被改过名字；不按“无尽/量子”名称删除用户改用的其他接口。
4. 遇到相同名称或相同 URL 的已有配置，不覆盖接口、名称或启停状态。
5. 不清空收藏、观看历史、播放进度、下载记录；旧收藏中原源名仍保留，但退役接口已不存在时需重新搜索其他源。
6. 迁移完成后删除的新预设不会因为重启自动恢复。
7. 已损坏的源 JSON 不被预设覆盖；保存源列表失败时不提前写成功标记。

相同包名和签名的覆盖升级在首次打开时执行迁移，不需要清除应用数据。若卸载或清除数据，按新装处理，不能据此期待保留原来的本地记录。

## 4. 验证与边界

已执行：

- Dart 格式化。
- `flutter analyze`：无问题。
- `flutter test --reporter expanded`：**62 项通过**。
- 回归覆盖七源初始化、五个新增版本标记、退役 URL 清理、自定义接口/停用状态保留、v1 空列表升级、已删除旧预设不恢复、收藏等本地记录保留、损坏配置与写入失败保护、重启后删除状态保留。
- 既有禁用源不发请求、单源故障不阻断其他源、三栏 UI/分类/分页等测试继续通过。

没有执行：APK 构建、MuMu/手机操作、实际播放器解码、完整视频下载、离线播放、全片库可用性检查。源检查使用有超时和响应大小上限的固定请求，不作全站采集。

搜索使用 `ac=videolist&wd=`，详情使用 `ac=detail&ids=`，分类使用 `ac=list&pg=1`，首页使用 `ac=videolist&pg=1`。核对非空结果、详情 ID、分类列表和媒体字段；只检查少量 HLS 清单。没有请求加密密钥，没有关闭证书验证，没有绕过拒绝访问。

建议自行打包后从“我的 → 设置”检查源表，再验证“搜索 → 详情 → 播放”和支持格式的下载。HLS 清单含 AES-128 不等同于证明 DRM，但当前下载器会拒绝加密分片；不能承诺所有影片可下载。多个源不代表自动跨站续播或同名条目合并。
