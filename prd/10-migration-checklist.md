## 分项实施与验收记录（2026-10-14～15）

### 1. 首页栏目
- **实现：** 三个栏目改用多源目录，保留海报、更新信息及更多入口，失败来源可查看和重试。
- **验证：** 首页导航、空/错误状态和免责声明回归；对应三个频道的真实目录均非空。
- **卡点：** 目前是公开源更新推荐，不是真实热度；保留“更新推荐 · 非平台热度”说明。
- **下一步：** 核实原运营目录接口，MuMu 上对照原页面和排序。

### 2. 电影聚合
- **实现：** 新增 `lib/directory.dart`；每源独立读取分类树，优先请求叶子分类，每次只传一个该源的分类 ID；轮转分页，最多三个并发 worker。
- **去重：** 规范化片名+年份+分类大类，保留各源变体；缺少年份时保守处理，不激进合并翻拍和季度。
- **容错：** 单源失败不清空其他源；来源变动后旧代请求失效；分类不可读与真实空内容分别说明。
- **验证：** 实际电影首批 132 条源记录，聚合为 90 个作品；不是全目录总数，也不是假数据。
- **下一步：** MuMu 点击、分页、来源状态和详情导航验收。

### 3. 其他频道
- **实现：** 电视剧、综艺、动漫、短剧等复用多源分类树聚合，不为未知频道编造内容。
- **验证：** 最终一轮实际电视剧首批 130 条源记录/89 个作品，综艺 130/70，动漫 130/85；数字随公开源更新变化。
- **局部故障：** 本轮如意资源分类请求失败，其余来源仍返回内容。
- **卡点：** AI 漫剧、直播及原应用真实排行榜没有已确认的独立服务；当前榜单明确是聚合更新列表。
- **下一步：** 接入核实且允许使用的数据服务，不能把公开源聚合称为完整迁移原后端。

### 4. 手机与 MuMu
- **实现：** `PhoneViewport` 手机使用实际宽度，宽窗口居中且内容最多 480 逻辑像素，同步内部 `MediaQuery`；不擅自强制设备方向。
- **验证：** 320、390、1280 宽度测试；追加详情 1.4 倍字体测试，修复播放器控制条横向溢出，进度条独占一行。
- **未验证：** 真实 MuMu 密度、方向、窗口和原生视频视图。
- **下一步：** 安装调试包，在 MuMu 对照截图；不以 widget 测试代替设备验收。

### 5. 数据来源调查
- **已确认：** 原 APK 既有取证只确认十个实际播放器输入 URL，以及“独家T”“官方①”等线路标签。
- **未确认：** 首页推荐、榜单、搜索、分类、详情的完整 API；没有证据证明来自某个特定平台。
- **平台辨别：** 当前预设“猫眼资源（第三方）”不是已确认的猫眼官方推荐/榜单服务。
- **卡点：** Flutter Dart AOT 不是完整 Dart 源码；大型 `.readme` 资源的格式和解密调用链尚未恢复。
- **边界：** 播放输入不当作目录接口；没有绕过 TLS、鉴权、DRM 或私有加密。
- **下一步：** 根据可正常访问的原页面、公开/获授权接口文档等证据继续核实。在此之前只验收独立聚合实现。

### 6. 详情元数据
- **实现：** 补充导演、语言、时长的 CMS 解析和持久化，保留海报、片名、年份、地区、分类、演员、更新、简介；按所属源的资源 ID 请求详情。
- **验证：** 字段编解码、失败重试保留条目、离开页面不更新已销毁状态；旧代详情不覆盖当前源。
- **卡点：** 字段来自公开 CMS 的 `vod_*`，不是原详情服务；源未提供的字段不捏造。
- **下一步：** MuMu 核查海报、长文本、真实字段与原界面结构。

### 7. 搜索
- **实现：** 所有启用源、最多三个 worker、精确/前缀/包含排序、同作品去重保留变体；分类筛选、海报元数据、折叠“来源状态”。
- **验证：** 去重、电影/电视剧过滤、新搜索取代旧响应、停用来源后旧响应不得恢复结果；单源失败不阻断其他源。
- **真实接口：** 关键词“三体”取得 47 条源记录，聚合为 17 个作品；一个来源请求失败。选中条目的详情 ID 一致，返回一条受支持 URL 的播放线路，但没有请求媒体或验证实际播放。
- **卡点：** 原搜索协议和逐像素视觉一致性未确认。
- **下一步：** MuMu 真实关键词、输入法、筛选和同名作品匹配测试。

### 8. 详情到播放
- **实现：** 内嵌播放器、来源选择、查找更多源、线路/选集及现有下载分享入口；默认优先受支持的可播放源变体。
- **切源：** 优先匹配集名/集数，例如“第02集”与“EP2”；只为确认匹配的集传递当前位置，避免把另一集当作同集续播。
- **收藏/历史：** 同片名+年份+分类大类的源变体共享收藏判断；历史界面同作品只展示最新来源，内部仍保留各源记录供下载元数据查找。各集进度和下载键仍按源条目及媒体 URL 隔离。
- **下载边界：** 现有前台 MP4/WebM、无加密 HLS；不宣称支持直播、DRM 或原应用后台任务。
- **验证边界：** widget 测试使用原生通道测试桩，仅验证布局与状态，不代表 Media3 实际播放。
- **下一步：** MuMu 原生初始化、真实播放、换源、集数/进度连续性、下载和本地回放分别验收。
